## 결정 (2026-11-06 사용자 「제안대로」 — 각 항목의 「제안」 쪽으로 확정)

1. **모니타의 높임**: 하십시오체 기본(제안) / 해요체 기본 / 둘을 섞음(서술은 하십시오체, 부탁은 「~해 주세요」)
2. **アナタ(17곳)**: 「손님」으로 / 「당신」으로 / 문맥상 빼기. 원문은 대명사라 「손님」은 관계어를 덧붙이는 셈이라, 제안은 **문맥상 빼고, 꼭 필요하면 「손님」**
3. **플레이어 이름 + さん**: 「○○ 님」(제안) / 「○○ 씨」
4. **닌자성 「どの(殿)」**: 「○○ 공」(제안, 사극 느낌) / 「○○ 님」
5. **다크 모니타**: 해요체로 모니타와 구별(제안) / 모니타처럼 하십시오체
6. **어트랙션 팁 「~してみよう」**: 원문대로 「~해 보자」(제안) / 「~해 보세요」
