# 닌텐도 랜드 번역 규칙 (5단계 번역 본작업용, 2026-11-06)

번역하는 사람(사람·AI 모두)이 지킬 규칙. 용어는 `translation/glossary.json`(사람용 `docs/glossary.md`), 말투는 `docs/tone.md`.

## 1. 원문 충실
- 번역은 그럴싸한 한국어를 새로 쓰는 일이 아니다. **원문 단어·표현·문장 종류를 살린다.** 원문에 없는 말을 붙이지 않고, 있는 말을 빼지 않는다. 단정↔질문을 바꾸지 않는다.
- ~~원문 한자어는 같은 한자의 한국어 낱말이 있으면 그 낱말로~~ → 11/17부터 새 번역 규칙 2-1: 한자어를 1:1로 옮기지 않고 한국에서 실제로 쓰는 말을 고른다(용어집 낱말은 그대로).
- **11/17 다시 번역부터 메모리 `jp-translationese-rules.md`(새 번역 규칙)가 이 문서보다 앞선다.**
- 말장난은 원문 글자 뜻만으로 살릴 수 있는지 먼저 찾고, 덧붙이거나 바꿔야 하면 note 에 원문·번역을 적어 사용자 결정을 받는다.
- 짧은 외침·감탄 한 줄도 추가·누락 없이.
- 영어판(en)은 **뜻·화자·부호 확인용 참고**다. 영어판의 의역·농담을 따라가지 않는다(영어판은 내용을 많이 바꿨다).
- 원래 영어로 나오는 문구(GamePad, Wii U, Miiverse, OK, NL 등)는 영어 그대로.

## 2. 같은 말 일괄 번역 금지
- 같은 원문이 여러 줄에 나와도 **줄마다 화자·상대·장면을 보고 다시 판단**한다. 고유명사·용어만 용어집으로 통일한다. 감탄사·호칭·어미·맞장구는 장면별로 고른다(「그렇구나」 반복 금지).
- 원문에 없는 관계어(고모·형 등)를 덧붙이거나 이름을 호칭으로 바꾸지 않는다.

## 3. 말투(높임) — `docs/tone.md`
- 모니타 → 손님: **하십시오체**(안내원). 부탁은 「~해 주십시오」. 가타카나 어미(デス·マス)는 흉내 내지 않는다. ワタクシ=저. アナタ는 문맥상 빼고, 꼭 필요하면 「손님」.
- 모니타(수련, 닌자성) → 플레이어: 하십시오체, 「どの」=「○○ 공」.
- 모니타 공주(닌자성) → 플레이어: **하오체**(사극), わらわ=나, そなた=그대, どの=「○○ 공」.
- 가짜 공주: 반말 악당. 다크 모니타(피크민): **해요체**, 장난스럽게.
- 석상 명판(◆…◆): 원문처럼 명사로 끝냄. 뒤의 모니타 한마디는 하십시오체.
- 시스템 안내: 「~하세요·~할 수 있습니다·~되었습니다」. 게임 밖 조작 확인(저장·종료·설정)은 「~하시겠습니까?」, 게임 안 행동 확인은 「~하겠습니까?」.
- 어트랙션 팁의 「~してみよう·~しよう」: **「~해 보세요·~하세요」**(11/17 사용자: 게임 안 안내문은 모두 존댓말 기본, 해요체). 큰 글씨 미션 목표 명령은 명령형 그대로.
- 플레이어 이름 변수 뒤 さん: 「님」(예: `{6:1:00000000}님`). 원문에 さん이 따로 있으면 그 자리에.
- 같은 상대에게는 한 높임으로 맞춘다(장면 안 한두 줄 전환은 기본 높임으로).

## 4. 문장부호
- **문장부호를 잘 살린다. 「여기에 마침표를 찍는 게 맞나?」 싶으면 영어판(en) 같은 줄에 마침표가 있는지 보고 따른다.**
- 종결어미로 끝난 문장은 마침표. 줄바꿈 앞에서 끝나는 문장도 부호(일본어는 줄바꿈이 문장 경계라 부호가 없음). 단 호칭·도치·감탄사 앞 줄바꿈은 쉼표 역할이라 부호 없이.
- 명사구·메뉴 항목·고유명사·버튼 이름·제목 줄·한 줄짜리 UI 안내에는 마침표 없음. 명사형 끝맺음은 대사(문장 역할)일 때만 마침표.
- 말줄임표·물결표 뒤 마침표 금지(`…` `~`로 끝냄, `…!` `…?` `~!` 허용). `~,`도 금지.
- 완결된 문장 뒤는 쉼표 말고 마침표. 원문의 「！」「？」는 그대로 「!」「?」(반각).
- 일본어 띄어쓰기(문장 사이 전각 공백)는 한국어 문장부호·띄어쓰기로 바꾼다. 전각 부호(！？：～)는 반각으로. 「・」는 「·」.
- 비명·웃음만으로 된 줄은 마침표 없음.

## 5. 태그·줄바꿈·창 폭
- `{숫자:숫자:…}` 태그는 **글자 그대로 모두 남긴다**(색 `{0:3:0002}…{0:3:ffff}`, 변수 `{6:1:…}`·`{3:20:…}`·`{4:5:…}`, 크기 `{0:2:…}`). 위치는 한국어 어순에 맞게 옮겨도 되지만 색 태그는 같은 낱말을 감싸야 한다.
- 후리가나 태그 `{0:0:…}`는 이미 빠져 있다(넣지 않는다).
- 사용자 정의 글자 ``~``(버튼·스틱 아이콘, 예: `` A 버튼)는 **개수 그대로** 남긴다. 아이콘 앞뒤 띄어쓰기는 원문처럼.
- `\n` 줄바꿈: 한 줄 최대 글자 수(`max_chars`, 한글 기준·띄어쓰기는 약 0.5자)와 최대 줄 수(`max_lines`)를 넘지 않게 다시 나눈다. 의미 단위로 자르고, 원문 줄 수와 비슷하게.
- `max_chars` 가 비어 있는 줄(rel)은 원문 길이와 비슷하게(넘기면 note 에 적기).
- 음성이 나오는 줄(voiced)은 들리는 원문 길이·어순에 가깝게, 풀어서 늘리지 않는다.

## 6. 표기
- 외래어는 국립국어원 표기법(대미지·메시지·타깃 등). 단 용어집에 공식 표기가 있으면 용어집 우선(스타쉽 등).
- 일본어 음역: 청음 카·타·치 / 탁음 가·다·지 구별, つ=츠. 모르면 note 에 적고 묻기.
- 1인칭 강조 직역 금지(「この私が」→「제가」). 직역투 금지(「~을 향해」·「~해 버렸다」 과잉·「4개의 X」 등).
- 대사 속 「그녀·그들」을 한 대사에 반복하지 않는다.
