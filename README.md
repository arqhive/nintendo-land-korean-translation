# 닌텐도 랜드 (Wii U) 한글 패치

「Nintendo Land」(Wii U, 일본판 `0005000010101F00`) 비공식 한국어 팬 패치입니다.
대사는 일본어판 원문을 기준으로 번역했습니다.

**제작: arqhive** · **최신 버전: [v0.1](../../releases/tag/v0.1)**

- 모니타의 안내 대사, 어트랙션 12종의 설명·대사, 메뉴·안내문, 석상 설명 등 메시지 2,660개를 한글화했습니다.
- 게임 폰트 4종에 한글을 새로 그려 넣었습니다(티머니 둥근바람). 점수 숫자 폰트 2종에는 단위 글자를 넣었습니다(안동 엄마까투리체).
- 글씨가 그려진 그림(닌자성 기술 이름 3장, 일본판 전용 어트랙션 로고 2종)을 한글화했습니다.
- 닌텐도 시리즈의 고유명사는 한국에 정식 발매된 작품의 표기를 따랐습니다.
- **가지고 있는 일본판 게임 파일로 한글판을 만드는 패처로 배포합니다.** 결과는 Wii U 실기(SDCafiine)와 Cemu 에서 바로 쓸 수 있습니다.

> 이 저장소에는 롬·그래픽 같은 게임 데이터가 들어 있지 않습니다.
> 패치를 만들거나 적용하려면 본인이 소유한 게임에서 직접 덤프한 원본이 필요합니다.

## 사용자용: 패치 적용

### 준비물

- 일본판 「Nintendo Land」의 복호화된 게임 파일 두 가지. 각 폴더에 `code`, `content`, `meta` 폴더가 있어야 합니다.
  - 본편: 타이틀 ID `0005000010101F00`
  - 업데이트 v32: 타이틀 ID `0005000E10101F00`
  - 북미판·유럽판에는 적용할 수 없습니다.
- Windows 10 이상. 패처에 파이썬이 들어 있어 따로 설치할 것이 없습니다.
- Wii U 실기라면 Aroma 등 CFW 와 SDCafiine 플러그인.

### 배포 파일

| 파일 | 내용 |
|---|---|
| `ALCJ_KPatch_v0.1.zip` | 패처. 대사·폰트·그림 |

### 적용 방법

1. [배포 페이지](../../releases/latest)에서 `ALCJ_KPatch_v0.1.zip`을 받아 압축을 풉니다.
2. 본편·업데이트 게임 폴더가 함께 든 상위 폴더를 `패치하기.bat` 위에 끌어다 놓습니다. 두 폴더를 함께 골라 끌어다 놓아도 됩니다. 그냥 실행하면 경로를 물어봅니다.
3. 원본 찾기·확인 → 한글판 만들기 → 결과 확인이 끝날 때까지 기다립니다(2~3분). 원본 파일은 바뀌지 않습니다.
4. `ALCJ_KPatch_v0.1\출력` 폴더에 결과가 생깁니다.

#### Wii U 실기 (SDCafiine)

`출력\sdcafiine` 안의 내용을 SD 카드의 `wiiu\sdcafiine\`에 복사하고, SDCafiine 플러그인을 켠 채로 게임을 실행합니다.

```
sd:/wiiu/sdcafiine/0005000010101F00/NintendoLandKR/content/...
```

#### Cemu

`출력\cemu\NintendoLand_Korean` 폴더를 Cemu 의 `graphicPacks` 폴더에 넣고, 그래픽팩 설정에서 `Nintendo Land → Mods → Korean Translation`을 켭니다.

#### 오류가 날 때

| 메시지 | 원인·해결 |
|---|---|
| …원본을 찾지 못했습니다 | 본편·업데이트 폴더를 둘 다 넣어 주세요. 업데이트는 v32 여야 합니다. 이미 패치한 파일이나 다른 판, 암호화된 상태(.app)로는 안 됩니다. |
| 결과가 기준과 다릅니다 | 패치 파일이 손상됐을 수 있습니다. zip 을 다시 받아 주세요. |

패처는 원본 파일의 해시를 확인한 뒤 바뀐 부분만 바꿔 파일을 다시 만들고, 결과가 제작 환경에서 확인한 빌드와 해시까지 같은지 검사합니다.
자세한 방법은 패처에 들어 있는 `README_KO.txt`를 참고하세요.

### 실행 환경

- **확인함**: Wii U 실기(SDCafiine).

### 알려진 문제

- 전자 설명서는 일본어 그대로입니다.
- 플라자의 Miiverse 말풍선은 본체 글꼴로 나옵니다.

## 개발자용: 도구

번역 원본 가운데 게임의 일본어 원문이 통째로 들어 있는 추출물(메시지 전체 JSON·대사 텍스트·그림)은 저장소에 넣지 않았습니다.
번역문(`translation/ko/*.json`), 용어집(`translation/glossary.json`), 번역 규칙·말투표(`docs/`), 도구(`tools/`)가 들어 있습니다.

| 도구 | 하는 일 |
|---|---|
| `tools/build.py <버전>` | 메시지·폰트·그림을 넣어 한글판 파일 4개와 패치 데이터를 만듦 |
| `tools/make_patcher.py <버전>` | 배포용 패처 zip |
| `tools/nl_apply.py` | 원본 + 바뀐 안쪽 파일 → 한글판(빌드와 패처가 같이 씀) |
| `tools/nl_font.py` | 게임 폰트(BFFNT)에 한글 그리기 |
| `tools/gfx_build.py` | 그림 글자 한글화(BFLIM) |
| `tools/check_ko.py`, `tools/check_overflow.py` | 번역 검사(태그·아이콘·창 넘침·용어·부호) |
